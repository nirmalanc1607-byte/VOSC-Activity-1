# Tic-Tac-Toe Game

A simple and interactive two-player Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

## About the Project

This project was created as part of **VOSC Activity-1**.

The game allows two players to play Tic-Tac-Toe on the same device. Players take turns placing X and O on a 3×3 board. The game automatically checks for a winner or a draw.

## Features

* Two-player gameplay
* 3×3 Tic-Tac-Toe board
* Automatic turn switching
* Winner detection
* Draw detection
* Winning cells are highlighted
* Animated winning cells
* Score tracking for both players
* New Game button
* Responsive design for smaller screens

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start playing Tic-Tac-Toe.

No additional software or libraries are required.

## How to Play

1. Player X starts the game.
2. Click an empty cell to place your symbol.
3. Player O takes the next turn.
4. Continue taking turns.
5. The first player to get three of their symbols in a row, column, or diagonal wins.
6. If all cells are filled without a winner, the game ends in a draw.
7. Click **Play Again** to start another round.
